# 地图画与地图数据

[地图画生成器](../tools/map-art)有三种做法：直接写地图数据（不用摆方块）、平铺摆方块、立体阶梯摆方块。第一种产出存档里的地图数据文件，后两种还会给出可以载入游戏的施工文件。

它和[方块像素画生成器](../tools/pixel)的区别：

| | 方块像素画 | 地图画 |
| --- | --- | --- |
| 放进游戏的东西 | 结构文件，要真的盖出来 | `map_<#>.dat`，或地图色对应的方块施工图 |
| 画幅 | 16–256 格自由 | 固定 128×128，一张地图刚好 |
| 颜色 | 142 种方块的平均色 | 61 种地图基础色 × 4 档明暗 |

## 为什么三种模式颜色数不一样

地图一格记一个色号：基础色 61 种，每种有四档明暗。四档不是四种颜色，而是这一格相对北边那一格的高度——低一档、同高、高一档，还有一档只在深水里出现，摆方块做不出来。

| 模式 | 可用颜色 | 做法 |
| --- | --- | --- |
| 地图数据 | 244 色 | 不摆方块，四档直接写进文件 |
| 平铺 | 59 色 | 全部同高，只有一档可用；有两种基础色摆不出来 |
| 立体阶梯 | 177 色 | 靠逐行升降切换前三档 |

摆得出来的颜色，工具都挑了生存里容易拿到的实心整方块。树叶和水这两种基础色只能靠植物或水，游戏里摆不出图，所以从色板里排除。

## 立体阶梯怎么算

明暗档只取决于同一列里、北侧那一格的高度差，列与列互不干涉：比北侧低、同高、比北侧高，分别对应高度 -1 / 0 / +1。从地图最北端逐行累积，就是整张高度图。

两个要注意的地方：

- 最北侧那一行没有「北侧方块」，游戏会拿地图外的地形来比。工具会在边界外多铺一行，把第一行的档位固定下来。
- 高度差只比符号、不比大小，所以每一列都能整体平移。默认逐列把最低点对齐到 0，支撑方块最省；关掉「高度压缩」则全图共用一个基准，回到经典阶梯，通常会更高、更费方块。

预览里可以切到「高度图」视图核对起伏，统计栏给出总层数、总方块数与支撑方块数。

## 施工文件

摆方块的两种模式会多出三个下载项：

| 文件 | 用途 |
| --- | --- |
| `.litematic` | Litematica 投影，一个 Region 装下整幅图，含顶层方块、支撑方块与边界行 |
| `.schem` | WorldEdit / FAWE 的 `//paste` 直接粘贴 |
| 分块 `.nbt` ZIP | 按结构方块 48³ 上限切块，包内 `摆放说明.txt` 写明每块的相对位置 |

每根柱子从基准面往上填廉价支撑方块，最顶上那一格才决定地图色。支撑方块可以在参数里换成泥土、圆石、石头或橡木木板。

## 调参数时看什么

预览下方有平均 ΔE（原图与选中地图色的色差均值），调抖动、采样和调色时看这个数有没有变小就行。

- 抖动五种：无 / Floyd–Steinberg / Atkinson / Bayer 4×4 / Bayer 8×8。照片适合误差扩散，像素字与 logo 适合关掉。
- 采样：平滑模式保留渐变，像素模式保留硬边。
- 透明像素在游戏里是「未探索」，摆方块时会打断高度链，默认自动填白（也可选黑底）。
- 去孤立噪点只会归并真正零星的杂色，不会抹掉眼睛高光和边缘过渡。

## 地图数据与版本差异

| 游戏版本 | 地图文件位置 | 计数文件 | `give` 写法 |
| --- | --- | --- | --- |
| 1.20.4 | `存档/data/map_<#>.dat` | `data/idcounts.dat` | `filled_map{map:<#>}` |
| 1.21 ~ 1.21.11 | `存档/data/map_<#>.dat` | `data/idcounts.dat` | `filled_map[minecraft:map_id=<#>]` |
| 26.1 及以上 | `存档/data/minecraft/maps/<#>.dat` | `data/minecraft/maps/last_id.dat` | `filled_map[minecraft:map_id=<#>]` |

26.1 重排了整个存档目录。工具里的版本选择决定文件放哪、叫什么、`give` 怎么写，选错版本游戏就读不到。

编号不要乱填：存档用计数文件记着「最新地图编号」。编号与已有地图冲突会直接覆盖它；编号比记录值还大时，游戏下次发新地图仍从小编号排，可能反过来把你放进来的文件覆盖掉。最稳的做法是先在游戏里用空地图画一张，看它拿到几号，再回到工具用那个编号重新导出替换。

## 数据来源

地图基础色表、明暗系数与地图文件格式来自 Minecraft Wiki，方块与地图色的对应关系来自
[plonck/palette](https://github.com/plonck/palette)（MIT）导出的 `blocks.csv`。
代码层面的说明见仓库的 [TECHNICAL.md](https://github.com/lyynew/mcArt/blob/main/TECHNICAL.md)。

## 常见问题

**平铺和阶梯选哪个？** 图标、文字、logo 用平铺（只有一层，最好摆）；照片、渐变、人像用阶梯（颜色多三倍，但要管高度与支撑）。

**直接写数据还要摆方块吗？** 不用。颜色直接写进地图文件，`give` 出来的地图就能看；施工文件是另外两种模式才需要。

**地图放进去了但游戏里是空白？** 先确认三件事：文件位置和版本对不对、编号与 `give` 指令一致、进游戏前有没有退出存档（游戏运行时会把它自己的内存数据写回来覆盖）。

**支持基岩版吗？** 不支持，地图数据格式与命令都不同。
