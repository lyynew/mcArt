# 方块与材质

## 内置了多少方块

配色方块有 142 种，覆盖原版里适合做像素画的方块。每种方块有一个代表色，由 16×16 原版贴图逐像素平均而来，匹配时用的就是它。

[方块图鉴](../tools/atlas)里能看到 978 种方块（142 种配色方块 + 836 种识别扩展）的贴图、中文名与 ID，也能一键复制 `give` 命令。

## 十套预设方案

| 方案 | 说明 |
| --- | --- |
| 基本 | 八个分组去重后的通用套装，几乎不丢颜色。**默认** |
| 混凝土 | 纯色块最干净，单一材料最省事 |
| 羊毛 | 哑光、色偏柔和 |
| 陶瓦 | 整体偏暗偏灰，像素风更厚重 |
| 石材 | 石、土、砂岩，冷灰到暖棕 |
| 木质 | 木板与原木，暖调木头色 |
| 金属 | 铁金铜与宝石块，饱和度高、对比强 |
| 彩色 | 荧光、菌光、蛙明灯这类特殊彩色方块 |
| 全部 | 所有内置方块，选项最多但材料也最杂 |
| 自定义 | 自己勾选，想用几种用几种 |

换方案一律按原图重新匹配。

::: tip 该选哪套
先按「基本」出效果，看主要的色块落在哪些方块上，再决定换成同色系的单一材料。比如一张夜景图，混凝土的深色档不够，陶瓦的灰调反而更贴。
:::

## 贴图从哪来

内置的是 16×16 的原版分辨率，取自 Minecraft Java 版资源包。想往色板里加方块或重算代表色，见仓库的
[TECHNICAL.md](https://github.com/lyynew/mcArt/blob/main/TECHNICAL.md)。

## 用高清材质包预览

如果你有 Faithful 之类的材质包，可以在「真实材质」面板里把它换进来：

1. 点「选文件夹」，选中材质包里的 `assets/minecraft/textures/block/` 目录（也可以只把需要的 PNG 拖进上传区）；
2. 打开「画布用真实材质」，面板会显示已覆盖与跳过的数量。

文件名必须等于方块 ID，比如 `white_concrete.png`、`oak_planks.png`；对不上的会被跳过。覆盖只影响画布预览，导出的 PNG 与施工图始终是纯色。想恢复内置贴图，点「恢复内置贴图」即可。
