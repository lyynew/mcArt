# 方块与材质

## 内置了多少方块

**142 种**，覆盖原版里适合做像素画的方块。数据在 `src/core/blocks.ts`，每一条包含：

- `id` —— 方块 ID，如 `white_concrete`，也就是命令里 `minecraft:` 后面那段
- 中文名与所属分组（混凝土 / 羊毛 / 陶瓦 / 石材 / 砂土 / 木质 / 金属宝石 / 彩色 …）
- **平均色** —— 匹配时用的代表色，由 16×16 贴图逐像素平均而来
- 贴图文件名 —— 通常与 `id` 相同，少数带朝向的方块（原木、石英）另有 `_side` / `_top` 别名

图鉴里能看到全部 978 种（142 种配色方块 + 836 种识别扩展）的贴图、中文名和 ID，
也能一键复制 `give` 命令。

## 十套预设方案

| 方案 | 说明 |
| --- | --- |
| 基本 | 八个分组去重后的通用套装，几乎不丢颜色。**默认** |
| 混凝土 | 纯色块最干净，单一材料最省事 |
| 羊毛 | 哑光、色偏柔和，老派地图画首选 |
| 陶瓦 | 整体偏暗偏灰，像素风更厚重 |
| 石材 | 石、土、砂岩，冷灰到暖棕，适合建筑风 |
| 木质 | 木板与原木，暖调木头色 |
| 金属 | 铁金铜与宝石块，饱和度高、对比强 |
| 彩色 | 荧光、菌光、蛙明灯这类特殊彩色方块 |
| 全部 | 所有内置方块，选项最多但材料也最杂 |
| 自定义 | 自己勾选，想用几种用几种 |

换方案一律按**原图重新匹配**，不会出现「换了大方案画布还不变」的情况。

::: tip 该选哪套
先按「基本」出效果，看主要的色块落在哪些方块上，再决定换成同色系的单一材料。
比如一张夜景图，混凝土的深色档不够，陶瓦的灰调反而更贴。
:::

## 贴图从哪来

`原版材质/` 目录里是 142 张 16×16 的 PNG，取自 Minecraft Java 版资源包，
是**贴图与平均色的唯一来源**。`材质清单.txt` 记录了分组、色值与文件名对照。

构建时 `scripts/sync-textures.mjs` 会把它们增量拷贝到 `src/assets/textures/`，
再交给 Vite 做内容哈希输出。`dev` / `build` 之前会自动跑，所以要加新方块：

1. 把 PNG 放进 `原版材质/`，文件名用方块 ID；
2. 在 `src/core/blocks.ts` 补一条数据（中文名、分组、平均色）；
3. 重新 `npm run dev`，同步脚本会带上新文件。

平均色可以用 `.build/` 下的 Python 脚本重新生成，`npm run fixtures` 会用旧版实现把算法基准重跑一遍。

## 用高清材质包预览

内置贴图是 16×16 的原版分辨率，放大到每格 20px 会有点糊。如果你有 Faithful 之类的材质包，
可以在「真实材质」面板里把它换进来：

1. 点「选文件夹」，选中材质包里的 `assets/minecraft/textures/block/` 目录；
   （也可以只把需要的 PNG 拖进上传区）
2. 打开「画布用真实材质」；
3. 面板会显示「已覆盖 N 张」。

**文件名必须等于方块 ID**，比如 `white_concrete.png`、`oak_planks.png`。
对不上的文件会被跳过，面板会告诉你跳过了多少张。

覆盖只影响画布预览。**导出的 PNG 与施工图始终是纯色**——施工图要的是看得清边界和坐标，
不是好看。想恢复内置贴图，点「恢复内置贴图」即可。
