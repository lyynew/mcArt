# 结构文件与进游戏

生成器导出的 `.nbt` 是 **Java 版结构文件**（structure NBT），不是基岩版、也不是 WorldEdit 的 schematic。
它在游戏里的用法是：放一个**结构方块**，切成「加载」模式，填上名字，按下加载。

## 一次能装多少

结构方块单次加载上限 **48×48×48**。生成器的画幅最大到 256 格，所以：

| 画幅 | 导出结果 |
| --- | --- |
| ≤ 48 | 一个 `.nbt`，直接加载 |
| > 48 | 切成 `ceil(N/48)²` 块，打包成 `.zip`，附带 `载入说明.txt` |

比如 96 格会切成 4 块（2×2），256 格会切成 36 块（6×6）。

## 朝向有两种

- **平铺地面**（flat）——尺寸 `N × 1 × N`，躺在地上，适合地画、停机坪、广场
- **立到墙上**（wall）——尺寸 `N × N × 1`，竖起来，适合墙面装饰、招牌

立起来的时候，分块会**从最高处往下对齐**，而不是简单地从地面往上堆——这样多块拼起来时上边缘是齐的。

## 空格填不填空气

- 开：空格写进结构文件，加载时**会把原位置清空**。替换旧画、覆盖原有地形时用这个。
- 关：空格跳过。往已有建筑上叠加、或者背后想保留原样时用这个。

默认是关的。如果你发现加载后背景没被清掉，就是它。

## 进游戏的四步

1. 导出 `.nbt`（或者解压 `.zip`）。文件名就是你在「结构文件」面板里填的结构名。
2. 把文件放进存档的结构目录：

   ```
   .minecraft/saves/<你的存档>/generated/minecraft/structures/<结构名>.nbt
   ```

   版本较老（1.13 之前没有 `generated` 层级）的存档，路径是 `saves/<存档>/structures/`。
   目录不存在就自己建。

3. 进游戏，`/give @s structure_block`，把它放在要生成的位置附近。
4. 右键打开结构方块，模式切到 **加载（LOAD）**，在名称里填 `<结构名>`，
   相对位置填 `0 0 0`，点 **加载**。

::: tip 结构方块的方向
结构方块是「以自己为中心的一角」来确定位置的。想精确对齐，先把结构方块放在地画的西北角，
相对位置填 `0 0 0`；位置偏了就把相对位置当成微调旋钮，一格一格挪。
:::

::: warning 先在存档副本里试
导出的结构文件在语法上是标准 NBT，但不同版本对方块状态 ID 的处理有差异。
正式施工前，先在存档副本里加载一次看看，比盖到一半发现颜色不对划算。
:::

## 分块之后怎么拼

`.zip` 里有 `载入说明.txt`，逐块写明了文件名与相对位置：

```
xxx_x0_z0.nbt   尺寸 48×48   放在  0 0 0
xxx_x48_z0.nbt  尺寸 48×48   放在 48 0 0
```

按说明摆结构方块即可。每块的坐标是**块内局部坐标**算出来的相对位置，不需要自己换算。

## 附带的两个图

- **施工图 PNG（带坐标）** —— 每格标了行列号，盖的时候按坐标数格子，比对着预览图猜位置靠谱
- **材料清单 CSV** —— 每种方块的数量，可以直接拿去算要挖多少、要烧多少

材料清单统计的是**结构文件里的方块数**（填了空气的话空气不算），和画布上看到的一致。
