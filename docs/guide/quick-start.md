# 快速开始

五分钟拿到第一张能进游戏的方块画。

## 1. 打开生成器

[方块像素画生成器](../tools/pixel)。第一次打开会有一张示例图，先看效果也行。

原图有三个入口：拖进左上角「原图」区域、点击选择文件，或直接 `Ctrl+V` 粘贴截图。
图片只在本地读入，不会上传。

## 2. 定画幅

「规格」里选边长格数。预设 32 / 48 / 64 / 96 / 128 / 160 / 192 / 256，也可以拖滑杆在 16–256 之间微调。

| 画幅 | 适合 |
| --- | --- |
| 32–48 | 图标、小 logo、头像。细节靠形状不靠颜色 |
| 64–96 | 常规立绘，导出一个文件就完事 |
| 128–256 | 大图、合影、壁画。超过 48 格会自动切块，导出一个 zip |

不确定就从 64 试。画幅翻倍，方块数量是四倍，施工时间也是四倍。

## 3. 选方块方案

「方块色系」里挑一套。默认的**基本**几乎不丢颜色，先用它看效果。

- 材料单一好采购：混凝土、羊毛、陶瓦
- 想要风格：石材、木质、金属、彩色
- 想榨干还原度：全部（142 种，材料最杂）
- 自己有想法：自定义，勾选想用的方块

换方案会重新匹配，手画过的格子会保留。

## 4. 微调

对比度和饱和度只影响匹配前的取样，照片发灰就加对比度，颜色过艳就降饱和度。

「显示」里的开关分两类：网格线、方块质感只影响预览；去杂点和颜色抖动会改变结果。
抖动可以选算法和强度，默认关闭——大面积纯色区会出现噪点，强度 0% 等于没开。

## 5. 导出

右侧「图片导出」：

- 纯净像素图 PNG，看结构用
- 施工图 PNG（带坐标），照着铺的时候看这张
- 材料清单 CSV，每种方块要多少个

「结构文件」里填名字、选朝向、决定空格要不要填成空气，然后导出。想要 Litematica 投影或 WorldEdit 图纸，选 `.litematic` / `.schem`。进游戏的步骤见[结构文件与进游戏](./structure-file)。

## 桌面端的快捷操作

- 滚轮缩放，空格 + 拖动平移（触屏是双指缩放/平移）
- `Ctrl+Z` / `Ctrl+Shift+Z` 撤销重做
- 物品栏选中方块后点击画布即落子；右键画布可以取色

## 下次打开还在

编辑偏好和画布草稿都保存在浏览器本地，刷新或关掉再回来会接着上次的状态。想彻底清掉，删除本站的站点数据即可。
