# 快速开始

目标是五分钟内拿到第一张能进游戏的方块画。

## 1. 打开生成器

[方块像素画生成器](../tools/pixel)。第一次打开会自动生成一张示例图，先看效果也行。

原图有三个入口，挑顺手的：

- 拖进左上角的「原图」区域
- 点击该区域选择文件
- 直接 `Ctrl+V` 粘贴剪贴板里的图片（截图之后最常用）

图片会在本地读入，不会上传到任何服务器。

## 2. 定画幅

「规格」里选边长格数。预设八档：32 / 48 / 64 / 96 / 128 / 160 / 192 / 256，也可以拖滑杆微调到 16–256 的任意值。

怎么选：

| 画幅 | 适合 |
| --- | --- |
| 32–48 | 图标、小 logo、单个人物头像。一格一个像素，细节靠形状不靠颜色 |
| 64–96 | 常规立绘。结构方块一次能装下，导出一个文件就完事 |
| 128–256 | 大图、多人合影、壁画。**超过 48 格会被自动切块**，导出的是打包好的 zip |

不确定就从 64 试。画幅翻倍，方块数量是四倍，施工时间也是四倍。

## 3. 选方块方案

「方块色系」里挑一套。默认的**基本**是八个分组去重后的通用套装，几乎不丢颜色，先用它看效果。

- 材料单一好采购：**混凝土**（纯色最干净）、**羊毛**（哑光柔和）、**陶瓦**（偏暗厚重）
- 想要风格：**石材**、**木质**、**金属**、**彩色**
- 想榨干还原度：**全部**（142 种，材料最杂）
- 自己有想法：**自定义**，勾选想用的方块

换方案会按原图重新匹配，画布立刻刷新；你**手画过的格子会被保留**，不会被覆盖。

## 4. 微调

调色面板的对比度和饱和度只影响匹配前的取样，照片发灰就加对比度，颜色过艳就降饱和度。

「显示」里的开关分两类，值得分清楚：

- **只影响预览**：网格线、方块质感、聚焦选中方块
- **会改变匹配结果**：去杂点（把孤立且颜色接近的格子并到周围）、颜色抖动（算法与强度可调：Floyd / Atkinson / Bayer，用噪点换更自然的渐变色带）

抖动默认是关的——它会让大面积的天空出现噪点，除非你确实需要那条渐变；强度拉到 0% 等于没开。

## 5. 导出

右侧「图片导出」：

- **纯净像素图 PNG** —— 一格一个纯色方块，看结构用
- **施工图 PNG（带坐标）** —— 每格标行列号，照着铺的时候看这张
- **材料清单 CSV** —— 每种方块要多少个

「结构文件」里填结构名、选朝向、决定空格要不要填成空气，然后导出 `.nbt`。
进游戏的步骤见[结构文件与进游戏](./structure-file)。

## 桌面端的快捷操作

- 滚轮缩放，空格 + 拖动平移（触屏是双指缩放/平移）
- `Ctrl+Z` / `Ctrl+Shift+Z` 撤销重做
- 物品栏选中方块后点击画布即落子；右键画布可以取色

## 下次打开还在

编辑偏好（方案、自定义勾选、物品栏、结构名）存在 `localStorage`，
画布与原图作为草稿存在 IndexedDB。刷新或关掉浏览器再回来，会接着上次的状态。
恢复有 600ms 上限，读不到就先给示例图，不会卡在加载上。
