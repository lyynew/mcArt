# 常见问题

## 图片会上传吗？

不会。整站是纯静态页面，没有后端，读图、缩放、色差匹配全在浏览器里完成。
断网也能用（已经把页面缓存下来的话）。

偏好（方案、勾选、物品栏、结构名）存 `localStorage`，画布与原图作为草稿存 IndexedDB。
想彻底清掉，浏览器里删掉本站的站点数据即可。

## 为什么出图偏灰 / 颜色不对？

按这个顺序排查：

1. **方案选得不对**。陶瓦整体偏暗偏灰，羊毛偏柔和，先用「基本」或「全部」看还原度上限。
2. **原图本身发灰**。调色面板加对比度，或者在原图上先做一次自动色阶。
3. **开了抖动**。抖动会在大面积纯色区插入噪点，视觉上会显得脏。
4. **画幅太小**。32 格只有 1024 个像素点，层次本来就不够。

## 换了方块方案，画布为什么还是一样？

不该出现。换方案会整图重算，这是修过的 bug（早期版本在小方案切大方案时不重算）。

如果确实没变，先确认两点：是不是选到了**相同方块集合**的方案（比如「全部」切到「自定义」但勾了全部）；
或者画布是不是被你手画的格子铺满了——手画遮罩优先级高于匹配结果，这是设计如此。

## 手画的格子会丢吗？

换方案、改画幅、重新生成都会保留手画的格子。但如果**改了画幅**（比如 64 → 96），
旧坐标对不上新网格，手画内容无法映射，会被清掉。

撤销最多 50 步，`Ctrl+Z` / `Ctrl+Shift+Z`。

## 缩到最小之后滚轮没反应？

也是修过的老问题：早期用「乘系数再取整」算缩放步进，2 × 1.15 = 2.3 取整回到 2，于是放大方向永久卡死。
现在步进是加法，最小 2px/格，最大按画幅算。

## 导出的 `.nbt` 加载后什么都没有？

按顺序检查：

1. 文件放对位置了吗？`saves/<存档>/generated/minecraft/structures/`，注意是**存档目录**不是 `.minecraft` 根目录。
2. 结构方块的名称填对了吗？填的是不带 `.nbt` 的文件名。
3. 相对位置是不是 `0 0 0`？偏了就是在别处生成了。
4. 结构方块的方向对不对？它是按自己的正面来确定朝向的。
5. 你导出的是**空的空气结构**吗？如果整张图都是空格并且开了「空格填成空气」，加载出来就是一片空气。

## 地图画和方块画该用哪个？

想**在游戏里盖一幅画**用方块像素画生成器，导出 `.nbt` 与施工图；
想**拿一张地图物品直接看图**用[地图画生成器](../tools/map-art)，它往存档里写 `map_#.dat`，
不用摆方块。前者画幅自由、能逐格改；后者固定 128×128、颜色是地图色而不是方块色。
细节见[地图画与地图数据](./map-art)。

地图画目前不做立体阶梯式地图画（那需要把明暗档反推成高度差，再生成方块施工图），
所以想真摆出来时只能在工具里切到「仅平面 61 色」。

## 地图放进去却是空白 / 被覆盖？

先确认四件事：游戏版本选对了吗（26.1 起路径和文件名都变了）、文件放在对应目录了吗、
`give` 里的编号与文件名一致吗、动文件之前有没有退出存档。
另外编号别超过存档记录的「最新地图编号」，否则游戏下次发新地图可能反过来覆盖它。
最稳的做法是先在游戏里画一张空地图拿编号，再用那个编号导出替换，详见[地图画与地图数据](./map-art)。

## 支持基岩版吗？

不支持。导出的是 Java 版结构文件与地图数据（gzip 压缩的 NBT），基岩版的格式不同。
做基岩版需要另一套导出器，目前不在计划里。

## 结构方块为什么只能 48 格？

游戏本身的限制，单次加载上限 48×48×48。生成器在画幅超过 48 时会自动切块，
打包成 zip 并附 `载入说明.txt`，逐块写明相对位置。见[结构文件与进游戏](./structure-file)。

## 能导入现成的结构文件查看吗？

可以，用[结构文件查看器](../tools/nbt)：拖入 `.nbt`，按层看方块分布、统计材料、检查尺寸。
它和生成器的导出是同一套格式，互为逆运算。

手上暂时没有文件也没关系：页面上点「先看个示例结构」会载入一份 32×32 × 16 层的金字塔，
可以拿它试滑杆、方向键切层和材料统计。

## 手机上为什么工具栏这么大？

`(pointer: coarse)` 下按钮和勾选框会按手指尺寸放大。桌面那套 22px 高的紧凑工具栏在手机上点不准。
手机上还额外做了：

- 单指绘制，双指缩放与平移，以捏住的那一格为锚点
- 物品栏长按 550ms 清空槽位（触屏没有右键）
- 输入框字号 16px，避免 iOS 聚焦时放大整个页面

10 英寸以下建议横屏作图，竖屏时舞台大概只占 58svh。

## 施工图为什么不是真实材质？

施工图要的是看清边界和行列号。真实材质会把画面搅乱，反而数不清格子。
所以导出的 PNG 与施工图始终是纯色，真实材质只用于画布预览。

## 能加自己的方块 / 自己的材质吗？

能，但要改代码：把 PNG 放进 `原版材质/`，在 `src/core/blocks.ts` 补一条数据，重新构建。
只想换预览贴图不用改代码——「真实材质」面板支持拖入 PNG 覆盖，文件名等于方块 ID 即可。
