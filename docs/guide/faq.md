# 常见问题

## 图片会上传吗？

不会。整站是纯静态页面，没有后端，读图、缩放、配色都在浏览器里完成。页面缓存下来之后断网也能用。

编辑偏好和画布草稿存在浏览器本地，想彻底清掉，删掉本站的站点数据即可。

## 为什么出图偏灰 / 颜色不对？

按这个顺序排查：

1. 方案选得不对。陶瓦整体偏暗偏灰，羊毛偏柔和，先用「基本」或「全部」看还原度上限。
2. 原图本身发灰。调色面板加对比度，或者在原图上先做一次自动色阶。
3. 开了抖动。抖动会在大面积纯色区插入噪点，视觉上会显得脏。
4. 画幅太小。32 格只有 1024 个像素点，层次本来就不够。

## 换了方块方案，画布为什么还是一样？

先确认是不是选到了相同方块集合的方案（比如「全部」切到「自定义」但勾了全部），或者画布是不是被手画的格子铺满了——手画内容优先于匹配结果。

## 手画的格子会丢吗？

换方案、重新生成都会保留。改画幅例外：比如 64 → 96，旧坐标对不上新网格，手画内容会被清掉。

撤销最多 50 步，`Ctrl+Z` / `Ctrl+Shift+Z`。

## 导出的 `.nbt` 加载后什么都没有？

按顺序检查：

1. 文件放对位置了吗？`saves/<存档>/generated/minecraft/structures/`，注意是**存档目录**不是 `.minecraft` 根目录。
2. 结构方块的名称填对了吗？填的是不带 `.nbt` 的文件名。
3. 相对位置是不是 `0 0 0`？偏了就是在别处生成了。
4. 结构方块的方向对不对？它按自己的正面确定朝向。
5. 导出的是不是一片空气？整张图都是空格、又开了「空格填成空气」，加载出来就是空的。

## 地图画和方块画该用哪个？

想在游戏里盖一幅画，用[方块像素画生成器](../tools/pixel)，导出结构文件与施工图；画幅自由、能逐格改。

想拿一张地图物品直接看图，用[地图画生成器](../tools/map-art)的「写地图数据」模式，往存档里放 `map_#.dat`，不用摆方块；固定 128×128，颜色是地图色。想真摆出来，用它的「平铺」或「立体阶梯」模式，会额外导出 `.litematic` / `.schem` 与分块 `.nbt`。规则与版本差异见[地图画与地图数据](./map-art)。

## 地图放进去却是空白 / 被覆盖？

先确认四件事：游戏版本选对了吗（26.1 起路径和文件名都变了）、文件放在对应目录了吗、`give` 里的编号与文件名一致吗、动文件之前有没有退出存档。

另外编号别超过存档记录的「最新地图编号」，否则游戏下次发新地图可能反过来覆盖它。最稳的做法是先在游戏里画一张空地图拿编号，再用那个编号导出替换，详见[地图画与地图数据](./map-art)。

## 支持基岩版吗？

不支持。导出的是 Java 版结构文件与地图数据，基岩版格式不同。

## 结构方块为什么只能 48 格？

游戏本身的限制，单次加载上限 48×48×48。画幅超过 48 时会自动切块，打包成 zip 并附 `载入说明.txt`，逐块写明相对位置。见[结构文件与进游戏](./structure-file)。

## 能导入现成的结构文件查看吗？

可以，用[结构文件查看器](../tools/nbt)：拖入 `.nbt` / `.litematic` / `.schem`，按层看方块分布、点格子查方块名、统计材料，画布可以缩放拖拽。

手上暂时没有文件也没关系：点「先看个示例结构」会载入一份金字塔，可以拿它试切层和材料统计。

## 手机上为什么工具栏这么大？

按钮和勾选框按手指尺寸放大了，桌面那套紧凑工具栏在手机上点不准。手机上还额外做了单指绘制、双指缩放与平移、物品栏长按清空槽位。10 英寸以下建议横屏作图。

## 施工图为什么不是真实材质？

施工图要的是看清边界和行列号。真实材质会把画面搅乱，反而数不清格子。真实材质只用于画布预览。

## 能加自己的方块 / 自己的材质吗？

只想换预览贴图不用改代码：「真实材质」面板支持拖入 PNG 覆盖，文件名等于方块 ID 即可。想往配色色板里加方块得改代码，见[方块与材质](./blocks-and-textures)和仓库的
[TECHNICAL.md](https://github.com/lyynew/mcArt/blob/main/TECHNICAL.md)。
