# 指南

这里讲四条最常用的路径：把一张图变成方块画、颜色是怎么匹配的、导出的结构文件怎么进游戏，
以及另一条产品线——把图直接写进地图物品。

如果你是第一次来，从[快速开始](./quick-start)看起，五分钟能出第一张图。

## 四个工具的分工

| 工具 | 输入 | 输出 |
| --- | --- | --- |
| [方块像素画生成器](../tools/pixel) | 一张图片 | 方块画预览、`.nbt` 结构文件、施工图、材料清单 |
| [地图画生成器](../tools/map-art) | 一张图片 | `map_#.dat`、`give` 指令、ZIP 说明包、PNG 预览 |
| [方块图鉴](../tools/atlas) | — | 方块 ID、平均色、贴图、`give` 命令 |
| [结构文件查看器](../tools/nbt) | 一个 `.nbt` | 分层视图、尺寸校验、材料统计 |

方块画三个工具共用同一份方块数据（`src/core/blocks.ts`）和同一套色差算法（`src/core/color.ts`），
所以图鉴里看到的平均色，就是生成器里参与匹配的那个颜色。地图画换的是调色板（游戏地图色）
与产物（地图数据文件），但颜色匹配仍复用同一个 `core/color.ts`。

## 这份文档的边界

文档只讲**能做什么、怎么做**。具体实现（数据结构、性能取舍、踩过的坑）写在仓库 README 的
「代码约定」一节里，改代码前建议先读一遍——那里记着几个看起来无害、实际会让编辑器卡死或变只读的写法。
