# 关于

mcArt 是一个 Minecraft 周边的小工具站：把图片变成方块画，把画变成结构文件，把结构文件再读回来看。

做它的起因很实际——网上的像素画生成器要么只给一张预览图，要么导出的格式进不了游戏，
要么把图片传到服务器上。这三件事都不难，自己做一遍更省心，于是就有了这个项目。

## 它能做什么

- **方块像素画生成器** —— 图片转方块画，可逐格修改，导出 Java 版 `.nbt`、施工图与材料清单
- **方块图鉴** —— 142 种方块的原版贴图、平均色与命令
- **结构文件查看器** —— 打开 `.nbt`，分层看结构、统计材料

## 它不做什么

- 不联机、不做社区、不存你的图
- 不支持基岩版结构文件（格式不同，得另写一套导出器）
- 不追求「一键生成完美结果」——像素画这件事，最后几格总要人自己调

## 技术栈

纯静态前端，没有后端：

- Vue 3 + TypeScript + Vite
- 文档站用 VitePress，工具页作为组件直接挂载在文档站里
- 颜色匹配：Lab 空间粗筛 + CIEDE2000 精算
- 结构文件：自己实现的 NBT 读写 + gzip / zip 打包

算法层（`src/core/`）不依赖 DOM，可以单测；测试拿旧版实现当基准，逐字节、逐格对齐。
