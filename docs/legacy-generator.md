# 方块像素画生成器 · 功能说明

> 这份文档从旧版 README 原样保留，描述的是**旧版单文件实现**的功能。
> 新版正在迁移中，逐项对齐后本文会被改写为面向新版的说明。
> 现在就想过一遍功能，打开 `public/legacy/index.html` 即可。

## 快速开始

1. 打开 `public/legacy/index.html`（双击即可，不需要装环境、不需要联网）
2. 把图片拖进左上角「原图」区域（也可以点击选择，或直接 `Ctrl+V` 粘贴）
3. 在「方块色系」里挑一套方块，等画面刷新
4. 想改造就动手画，满意后到「结构文件」里导出 `.nbt`

打开时会自动生成一张示例图，先看效果也行。

## 功能

### 转换

- 图片自动居中裁成方图，不拉伸变形；透明处保留为空格
- 六档画幅：32 / 48 / 64 / 96 / 128 / 160
- 按 **CIEDE2000** 色差匹配最接近的方块，比单纯比较 RGB 更贴近人眼观感
- 可调对比度、饱和度，处理发灰或过艳的原图
- 去杂点：只在四周都没有同类、且颜色确实接近时才合并，不伤眼睛和高光

### 142 种方块，8 个分组

全部自带原版材质。

| 分组 | 数量 | 分组 | 数量 |
| --- | --- | --- | --- |
| 混凝土 | 16 | 木质 | 16 |
| 羊毛 | 16 | 金属宝石 | 17 |
| 陶瓦 | 16 | 彩色 | 19 |
| 石材 | 29 | 砂土 | 13 |

十个色系方案：基本（102 种，八个分组去重后的通用套装）、混凝土、羊毛、陶瓦、石材、木质、
金属、彩色、全部（142 种）、自定义。

「自定义」可以自己勾选方块，支持搜索、全选、**只保留当前图用到的**，选择会存在本地，下次打开还在。

### 编辑工具

画笔、橡皮、吸管、填充、替换、抓手；1/2/3 格笔刷；左右对称绘制；50 步撤销重做。

- 滚轮以鼠标位置为中心缩放（2–64 px/格），空格或中键拖动画布
- 九格物品栏：先点格子，再点方块放进去，可重复、不会被顶掉，右键清空
- 聚焦某种方块时，其余颜色压暗，方便看分布
- 换色系会用新色板重新匹配原图，**手画过的格子会被保留**

### 导出

- `纯净像素图` PNG：纯色块，看得清
- `施工图` PNG：带每 8 格坐标，照图铺不会数错
- `材料清单` CSV：方块中文名、方块 ID、数量、占比
- `结构文件` `.nbt`：Java 版结构方块可直接加载，支持平铺地面 / 立到墙上两种朝向

## 结构文件怎么用

1. 导出后把 `.nbt` 放进
   `存档目录/.minecraft/saves/存档名/generated/minecraft/structures/`
   没有 `structures` 文件夹就自己建
2. 进游戏 `/give @s structure_block`
3. 放下结构方块，模式切成**加载**，结构名填文件名（不带 `.nbt`），点加载

结构方块上限 48×48。画幅更大时会自动切块，打包成 zip，每块的摆放坐标写在包内的
`载入说明.txt` 里。

## 换成自己的材质

内置的是 Java 1.21.4 的原版贴图。想用高清材质包：左栏「真实材质」里拖入 PNG 即可，同名会覆盖内置那张。

- 文件名 = 方块 ID，例如 `white_concrete.png`、`gold_block.png`
- 16×16 起都认，32/64 也可以
- 多面方块如 `quartz_block_side.png` 会自动匹配，不用改名

## 实现要点

- 单文件：样式、逻辑、142 张内置贴图（base64）都在 `index.html` 里
- `原版材质/` 是贴图原始 PNG，`.build/` 里的 Python 脚本从中算出每个方块的平均色
- 结构文件写入是自己实现的：NBT 序列化 + gzip（stored）+ zip（stored），不依赖第三方库
